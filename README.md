# User Guide

## Repository Branches

The project repository contains two branches with different purposes:

- **Main branch**: This branch contains all completed results, including the calculated outputs and visualization artifacts. It is ideal for users who want to review the code and inspect the generated results without running the experiments themselves.
- **raw-archi branch**: This branch contains only the source code without any pre-computed results. It is recommended for users who want to run the code independently and configure their own optimization parameters.

It is recommended to include this branch information in the user manual so that users can choose the most suitable branch based on their needs.

## Project Structure

The repository is organized into the following main folders:

```text
System-Code/
├── Data Generation/           # Data generation and visualization scripts
├── LSTM/                      # LSTM from-scratch implementation
├── LSTM-BNN/                  # LSTM-BNN implementation
├── LSTM-PLBNN/                # LSTM-PLBNN implementation
├── main.py                    # Testing file for uv
├── pyproject.toml             # Project configuration and dependencies
├── LSTM-PLBNN.pdf             # The preprint paper of this project
└── README.md                  # Project documentation
```

### Data Generation

This folder contains the scripts used to generate network traffic data and create visualizations.

- `data_generation.py` — generates a CSV file
- `virtualization.py` — uses the generated CSV to create visualizations

The visualization process produces four images corresponding to the four weeks of data available in the generated CSV.

### LSTM

This folder is used for the LSTM-based model workflow.

- `lstm_from_scratch.py` — generates a prediction results CSV and a JSON file for computational resource calculation
- `virtualization.py` — uses the newly generated prediction results CSV from `lstm_from_scratch.py`

> Users need to place the CSV generated by the Data Generation step into this folder before running the model.

## Optimal Project Setup with uv

This project uses `uv`, a modern Python package and project manager developed by Astral, to manage the virtual environment, Python dependencies, and execution workflow. Using `uv` simplifies project setup, reduces dependency conflicts, and minimizes configuration errors.

Since the source code is hosted on GitHub, users can reproduce the development environment by cloning the repository and synchronizing dependencies with `uv`.

### Install uv

```bash
pip install uv
```

Or:

```bash
pip3 install uv
```

### Setup Process

```bash
git init
git pull https://github.com/BoKu237723/LSTM-PLBNN
cd project_folder
uv venv
.venv\Scripts\activate
```

The `uv venv` command automatically creates a virtual environment (`.venv`) if one does not already exist and installs the dependencies recorded in the project lock file. Once the environment is prepared, the project can be executed.

## Deployment Benefits

This deployment approach simplifies setup for future developers, evaluators, and researchers while improving the reproducibility and maintainability of the system.
